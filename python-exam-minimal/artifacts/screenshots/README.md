Place the two required screenshots here with these exact names:

- feature_flag_off.png
- feature_flag_on.png

1. OFF screenshot: command/environment shows FEATURE_NEXT_RECOMMENDER=false and response model is baseline-v1.
2. ON screenshot: command/environment shows FEATURE_NEXT_RECOMMENDER=true and response model is next-v2.

These files are required for manual final submission checks.
